# 🧠 NEON MEMORY

> Киберпанк-головоломка на логику и память. Найди все пары неоновых символов до истечения времени.

[![Играть](https://img.shields.io/badge/🎮_ИГРАТЬ-0ff?style=for-the-badge)](https://matiazzqq.github.io/neon-memory/)

## Особенности
- 🃏 **3D Анимации**: Плавный переворот карт через CSS Transforms.
- 🎨 **Неоновый дизайн**: Светящиеся геометрические фигуры вместо обычных картинок.
- ⏱ **Динамический скоринг**: Очки зависят от скорости прохождения и количества ходов.
- 🔊 **Процедурный звук**: Все эффекты генерируются кодом (Web Audio API).
- 📈 **3 Уровня сложности**: Легкий, Средний, Хардкор.

## Технологии
- HTML5 / CSS3 (Grid Layout, 3D Transforms)
- Vanilla JavaScript (ES6+)
- Web Audio API

## Управление
Кликай по карточкам, чтобы перевернуть их. Совпадение двух одинаковых символов открывает их навсегда.
